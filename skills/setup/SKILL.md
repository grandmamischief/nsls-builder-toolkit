# Setup → use `/nsls-setmeup`

This is an alias. The onboarding flow lives in the `nsls-setmeup` skill, renamed
because `/setup` collides with other setup-named skills in the `/` menu (notably
Anthropic's `setup-cowork`), and builders were picking the wrong one.

**Invoke `nsls-setmeup` now** — use the Skill tool: `Skill(nsls-setmeup)`. Don't
re-implement or summarize the onboarding steps from memory; the real flow is
maintained in that skill and nowhere else.

Tell the builder once, in passing, that the command is now `/nsls-setmeup` — then
carry on with onboarding. Don't make them retype it.
